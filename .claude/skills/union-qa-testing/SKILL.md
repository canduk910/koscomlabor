# 테스트 — **화면이 깨지는가만 본다**

⛔ **문면이 맞는지는 테스트 항목이 아니다.** 내용은 사용자가 판정한다.
문자열을 세는 것은 **«우리가 넣은 것이 실제로 들어갔나»** 를 확인할 때만 쓴다.

## 1. 매번 하는 것

```
npm run build        타입·린트·빌드
브라우저 실측         아래 §2
프로덕션 확인         배포 후 curl 로 실제 페이지를 «값으로»
```

⚠ **빌드 성공 ≠ 배포 완료.** 배포 후 실제 URL 을 열어 확인한다.
⚠ 개발 서버를 재기동할 때는 **먼저 죽었는지 확인**한다 — `EADDRINUSE` 가 **종료코드 0** 으로 나와
낡은 서버가 응답한 사고가 있었다.

## 2. 브라우저 실측 — Playwright MCP 를 쓴다

⛔ `claude-in-chrome` 은 쓰지 마라 — 탭이 `hidden` 이면 `rAF`·`ResizeObserver` 가 안 돌아
**«없는 결함»을 만든다.**

### 측정 전에 «잴 수 있는 상태인가»를 확인한다
**측정값과 «함께» 적는다** — 없으면 다음 사람이 다른 조건에서 재고 «회귀»라고 한다.
```
뷰포트 · clientWidth · innerWidth − clientWidth(스크롤바) · devicePixelRatio
document.visibilityState · 루트 font-size
```
★ **루트가 12px 이다**(`html{font-size:75%}`). **16px 을 가정한 개산은 전부 틀린다.**
⚠ **「200%」가 두 값을 가리킨다** — 이 저장소 관행은 **루트 32px**, 참값은 **24px**. **어느 쪽인지 적어라.**

### 항목
| 무엇 | 참값 |
|---|---|
| **가로 스크롤** | `documentElement.scrollWidth ≤ clientWidth`. **기본 배율 + 200%** · 폭 `320·360·390` |
| **터치 대상** | 인접 대상 **2차원** 최소 간격 ≥ **24px**(WCAG 2.5.8). ⛔ 한 축 성분으로 판정하지 마라 |
| **포커스** | 탭으로 도달하는 모든 것에 **링이 «보이는가»**. 화면 밖 요소가 포커스를 받으면 결함이다 |
| **첫 화면** | `360×640` 에서 핵심 정보가 잘리지 않는가 |
| **링크** | 404 가 아닌가. 외부 링크는 실제로 열어 본다 |
| **이미지** | 요청된 `w`·`q`. ⚠ `quality` 는 `next.config.ts` 허용 목록만 유효(목록 밖이면 **400 → 조용히 75**) |

### 측정 위생
- **내가 바꾼 것을 되돌리고 «값으로» 확인**한다 — 인라인 스타일 · 주입 CSS · **`localStorage`**
  (글자 크기 슬라이더 값이 남으면 **이후 모든 측정이 오염된다**)
- **참값을 재라.** 프록시 금지 — 「행 높이로 줄바꿈 추정」 같은 것
- **«전부 실패»가 나오면 대상이 아니라 방법을 의심**한다. ★ **«절반만 실패»는 더 위험하다** —
  성공한 절반이 알리바이가 된다
- ⚠ **좌표를 클릭할 때는 «클릭 직전»에 무엇이 그 좌표를 덮고 있는지 읽어라.**
  이 저장소는 **모든 페이지에 높이 68px 고정 헤더**가 있다
