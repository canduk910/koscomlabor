# 노조 페이지 — 작업 진행

## ⛔ 먼저 — 내용 검증은 우리 일이 아니다

**사실·시각·장소·문면이 맞는지는 사용자가 판정한다.** 우리는 **그것을 정확히 구현**하고
**화면에서 깨지지 않는지 테스트**한다.

- 출처를 따지지 않는다 · 「게시 조건」을 만들지 않는다 · 사실 판정 문서를 만들지 않는다
- **사용자 지정 문면은 한 글자도 바꾸지 않는다**
- 자료가 어긋나 보이면 **판정하지 말고 묻는다**

## 기본은 «혼자» 한다

대부분의 작업은 **직접** 하는 것이 빠르고 정확하다. 다중 에이전트는 **왕복·기준선 불일치·중복 측정**을 만든다.

**에이전트를 쓰는 경우는 셋뿐이다:**
1. **구현이 커서 병렬이 실질 이득일 때** — `web-developer`
2. **브라우저 실측이 길 때** — `qa-tester`
3. **긴 호흡이 끝나 보고서를 낼 때** — `report-writer` (아래 「호흡이 끝나면」)

⛔ **워크플로(다중 에이전트 팬아웃)는 사용자가 명시로 요청할 때만 쓴다.**
★ *「하네스가 과하다」* 는 지적을 받은 적이 있다. **의심스러우면 혼자 한다.**

## 절차 — **긴 호흡으로 간다** (사용자 지시 2026-09-07)

★★ **한 덩어리 끝낼 때마다 멈춰 서서 묻지 마라.** 사용자는 «긴 호흡의 개발»을 요청했다.
   물어볼 것이 없으면 **다음 작업으로 계속 이어간다.** 보고는 호흡이 끝났을 때 한 번 한다.

```
[작업단위마다 반복]
  1. 무엇을 만들지 «사용자 문면 그대로» 확인한다   ← 애매하면 «묻는다»
  2. 구현
  3. 테스트 — 빌드 + 브라우저 실측(union-qa-testing)
  4. 커밋                    ← 승인받지 마라
  5. 테스트를 통과했으면 «즉시» 푸시 → 프로덕션에서 값으로 확인
  ↺ 남은 작업이 있으면 1 로 돌아간다

[호흡이 끝나면]
  6. report-writer 에게 아티팩트 보고서를 요청한다
```

### 커밋·푸시 — 승인 없이 한다

- **작업단위로 커밋한다.** 별도 승인을 받지 않는다. 단위는 «독립적으로 빌드되고 되돌릴 수 있는 것»
- **테스트를 통과한 건은 즉시 푸시한다.** 모아 두었다가 한꺼번에 올리지 마라 —
  실패했을 때 어느 변경이 범인인지 못 가린다
- ⛔ **테스트 전에 푸시하지 마라.** main 푸시는 곧 웹 프로덕션 배포다
- ⛔ **API(`server/`) 배포는 별개다** — CD 제외 + DB 마이그레이션이라 **사용자가 지시할 때** 한다

### 호흡을 «멈춰야» 하는 때 — 이때는 이어가지 마라

계속 가는 것이 기본이지만, 다음은 예외다. 그냥 밀고 나가면 되돌리기 어렵다.

1. **우리가 정하면 안 되는 것이 나왔다** — 화면 문면 · 사실 관계 · 자료 충돌 (아래 「묻는 것」)
2. **되돌리기 어려운 것을 하려 한다** — API 배포 · DB 변경 · 조합원에게 보이는 상태 전환
3. **사용자 요청 범위를 벗어난다** — 하려면 «왜 필요한지»를 대고 확인받는다
4. **같은 것을 두 번 고쳤는데 또 깨진다** — 방법을 의심할 때다. 혼자 세 번째를 시도하지 마라

### 호흡이 끝나면 — 보고서

**`report-writer` 에이전트**에게 아티팩트 보고서를 요청한다. 넘길 것:
- 이번 호흡의 **시작·끝 커밋**(`git log <시작>..HEAD`)
- **프로덕션 실측 결과** (직접 잰 값)
- **정해 주셔야 할 것**의 후보 — 미룬 것·갈림길·확인 못 한 것

⛔ **대화창에 보고서 전문을 쏟아붓지 마라.** 아티팩트 URL 과 3~4줄 요약만 남긴다.
⚠ 짧은 작업 하나로 끝났으면 굳이 부르지 마라 — **보고서는 «긴 호흡»의 마무리**다.

## 사용자에게 묻는 것

**우리가 정하면 안 되는 것만 묻는다** — 화면에 나갈 문면 · 두 자료가 어긋날 때 어느 쪽인지 ·
사실 관계. **선택지를 주고 기본안을 밝힌다.**

⛔ 구현 세부(클래스 이름·파일 구조·리팩터링)는 묻지 마라. 우리가 정한다.

## 기록

**「지금 사실」만 남긴다.** 회차별 판정 이력을 쌓지 않는다.

- **되돌림을 막는 것** → **소스 주석**(「하지 마라 + 왜」 한 줄)
- **미룬 것** → `_workspace/FOLLOWUPS.md`
- ⛔ **판정 이력 문서·절 번호 체계·기대 개수 계약을 새로 만들지 마라**

⚠ `_workspace/` 의 기존 산출물은 **지우지 않는다**(과거 기록). **다만 더 쌓지 않는다.**
