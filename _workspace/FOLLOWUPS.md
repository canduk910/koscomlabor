# 후속 과제 (미해결 · 범위 밖으로 남긴 것)

각 항목은 발견 경위와 근거를 함께 남긴다. 우선순위는 조합원 영향도 순.

## 1. 썸네일 치수 검사 없음 — 회색 플레이스홀더가 캐시될 수 있다

- **위치**: `server/src/lib/youtubeThumbnail.ts` (변형 취득부)
- **경위**: 디자이너가 `Vj3lQ7Y71PU`(오바마)의 `maxresdefault` 원본을 열어 보니
  **120×90 균일 `#cccccc`** — YouTube 의 "썸네일 없음" 플레이스홀더였다. QA 13회차가
  실제 응답이 **HTTP 404 + 그 본문**임을 확인해 현재 코드가 정상 폴백함을 검증했다
- **잔존 위험**: 우리 코드는 상태코드 200 · JPEG 매직바이트 · 2MB 상한만 본다.
  어떤 영상이 **200 으로** 회색 판을 주면 그대로 캐시되어 평평한 회색 박스(1.61:1)가
  썸네일로 나간다
- **권고 조치**: 매직바이트 검증 후 JPEG SOF 마커로 치수를 읽어, `maxresdefault` 가
  `width < 640` 이면 실패로 처리해 `mqdefault` 로 폴백
- **우선순위**: 낮음 (발생 확률 낮고, 발생해도 회색 박스일 뿐 오정보는 아니다)

## 2. 주석의 백틱 클래스명이 빌드 CSS 에 규칙을 생성한다

- **위치**: `src/components/board/PostList.tsx` · `src/components/home/HeroPanel.tsx` 의 주석
- **경위**: QA 13회차. Tailwind 스캐너가 주석 안의 클래스명 문자열까지 후보로 잡아
  `.border-urgent` 규칙과 `--color-primary-bright` 가 빌드 CSS 에 생성된다
- **영향**: 적용 요소 0건이라 **렌더 영향 0**, CSS 크기 미미
- **권고 조치**: 주석에서 클래스명을 백틱으로 감싸지 않거나 `.`/`-` 를 풀어 쓴다
- **우선순위**: 낮음 (위생 문제)

## 3. 게시물 수동 정렬 100건 초과 시 지정 불가

- **위치**: `src/components/admin/SortPanel.tsx` (100건 가드)
- **경위**: 정렬 계약 §3 #4 가 "해당 분류 활성 게시물 **전체의 순열**"을 요구한다 —
  낡은 목록으로 덮어써 순서가 누락·중복되는 것을 막는 낙관적 동시성 제어다.
  그래서 한 화면에 전체를 올려야 하고, 100건이 실용 상한이다
- **권고 조치**: 필요해지면 서버 계약을 "부분 순열 + 기준 버전(ETag)" 으로 확장.
  현재 게시물 수(분류별 한 자리)에서는 과설계
- **우선순위**: 낮음 (당장 도달하지 않는다)

## 4. uploads 볼륨 백업 미구현 — 첨부파일이 백업 대상이 아니다

- **경위**: `server/deploy/backup.sh` 는 `pg_dump` 만 한다. 06 명세 §13.3 이 예정했던
  첨부 tar 백업이 미구현이다
- **영향**: 썸네일은 재생성 가능한 파생 캐시라 무관하지만, **조합원에게 배포한 첨부
  문서(PDF 등)는 소실 시 복구 수단이 없다**
- **권고 조치**: `backup.sh` 에 `docker run --volumes-from` 으로 uploads tar 추가,
  기존 14일 롤링 정책 준용
- **우선순위**: **중간** — 첨부 게시물이 쌓이기 전에 넣는 것이 좋다

## 5. 노동교육 영상 링크 정기 점검

- **경위**: fact-verifier 1차 게이트. `오바마 대통령이 말하는 노조` 는 원출처 미표기
  개인 채널 재업로드로 **예고 없이 삭제될 수 있다**
- **잔존 위험**: 썸네일은 우리 서버에 캐시되어 계속 표시되므로, **링크는 죽고 썸네일은
  살아 있는** 상태가 된다 (조합원이 클릭하면 삭제된 영상 페이지)
- **권고 조치**: 외부 링크 도달성 정기 점검(수동 또는 크론). 5건 전부 대상
- **우선순위**: **중간**

## 6. 노동교육 영상 자막(캡션) 제공 여부 미확인

- **경위**: fact-verifier·QA 양쪽에서 미검증으로 남았다
- **영향**: 청각 장애 조합원 접근성
- **우선순위**: 중간
