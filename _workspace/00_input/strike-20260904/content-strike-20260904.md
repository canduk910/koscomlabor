## 리더가 지목하는 검증 쟁점

1. ★★★ **「(안)」 의 확정도를 페이지가 어떻게 지는가.** 제목·일시·장소·식순 각각.
2. ★★ **코스콤지부 위치를 말할 수 없다.** 결의대회 페이지 구조를 그대로 베끼면 **빈 자리가 생긴다** —
   그 자리를 «추후 안내» 로 채울지, 블록 자체를 빼는지.
   ⚠ 결의대회에서 *"확인 중이며, 확인되는 대로 지도에 반영하겠습니다"* 는 **우리 작업 상태 서술(A 유형)**
   이라 삭제된 전례가 있다(요구 157).
3. **인명 소속 병기** — 원문에 없다. 결의대회 값을 옮길 수 있는가.
4. **지도 이미지 파일이 없다.** 게시하려면 파일이 필요하다 → 리더가 사용자에게 요청한다.
5. **준비사항의 «(간부)» 한정** — 전 조합원이 «나도 조끼를 받나» 로 읽지 않게.
6. **결의대회 페이지와의 관계** — 8/28 은 지났다(오늘 8/29). 홈 배너를 무엇으로 바꾸고
   결의대회 페이지·배너는 어떻게 남기는가.
7. **날짜 단일 출처** — `src/lib/struggleSchedule.ts` 에 9/4 가 있는지. `rally.ts` 가 그 배열을 검증한다.
