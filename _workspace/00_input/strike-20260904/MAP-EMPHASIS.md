## 1. ① 선택 전/후 효과 — 확정 스펙

### 1-1. 채널 — 왜 «링»도 «그림자»도 «아웃라인»도 아닌가

이 페이지에서 그 셋은 **전부 임자가 있다.** 되돌리려는 사람을 위해 근거를 값으로 적는다.

| 후보 | 임자 | 자리 | 쓰면 나는 일 |
|---|---|---|---|
| `box-shadow` | ① 쉬는 그림자 `--strike-hit-shadow` ② **포커스 이중 링** | `globals.css:197-199 · 201-207` · `StrikeMap.tsx:205` | `:focus-visible` 이 `box-shadow` 를 **통째로 재선언**한다. 인라인으로 쓰면 `StrikeMap.tsx:205` 가 명시한 «링이 안 나온다»가 그대로 난다 |
| `outline` | **고대비(강제색) 모드 보험** | `globals.css:206` (*«그 모드는 `box-shadow` 를 지우고 `outline` 을 강제한다. 빼지 마라»*) | 보험이 죽는다 |
| «링» 문법 자체 | 포커스 표현 **3종** | `globals.css:181-186` (*«셋이 다른 것이 «설계»다 … «일관성»을 이유로 하나로 맞추지 마라»*) | 넷째가 아니라 **셋째의 변형**이 된다 |
| `transition`·애니메이션 | — | `globals.css:133-143` (`prefers-reduced-motion` 전역 `!important` 무효화) | 그 사용자에게 상태가 통째로 사라진다 |

**→ 남는 자리는 «요소 «안»(content-box)» 하나뿐이다.** 포커스 링은 요소 «밖»(0~4 px)에 그려지므로
**속성도 다르고 지면도 안 겹친다.** 이것이 이 처방의 성립 근거다.

### 1-2. 그림 — 참값

| 상태 | pill 3개(`koscom-area`·`gwanghwamun`·`cityhall`) | 화장실 배지 2개(`toilet-north`·`toilet-south`) |
|---|---|---|

| **선택** | **content-box 에 `#1a1a1a` 판** + 글자 `#ffffff`.<br>**padding 3/8 px 흰 링 · tone 1 px 테두리 · 그림자 그대로** | **content-box(17×17) 에 `#1a1a1a` 판.**<br>**점선 테두리 · 그 «틈»의 흰 바탕 · 흰 2 px 링 · 픽토그램 그대로** |

★ **판은 «안»에만 들어선다.** 타일과 맞닿는 픽셀(pill = tone 1 px 테두리 · 배지 = 흰 2 px 링)은 **한 개도 안 바뀐다.**
→ **WCAG 1.4.11 «노출»이 늘지 않는다**(§4).

### 1-3. 기전 — ⚠⚠ **배경 층은 «둘»이어야 한다. 이 한 줄이 이 처방의 단일 실패점이다**

CSS `background-clip` 의 콤마 목록은 **배경 «이미지 층» 수만큼만 살아남는다.**
`background-image` 가 **1층**인데 `background-clip: content-box, padding-box` 를 쓰면 둘째 값이 **버려지고**,
배경 «색»은 **마지막으로 «쓰인» 층의 클립**(= `content-box`)을 따른다.
그러면 **pill 7개 전부·모든 상태에서 흰 padding 면이 사라져 타일이 비친다.**

> 실측(반증 라운드 · Chromium · 2회 독립 재현):
> `background-image` **1층** + 2값 → `getComputedStyle().backgroundClip === "content-box"`
> `background-image` **2층** + 2값 → `"content-box, border-box"` (둘 다 산다)
> 그리고 **2층 형태로 쓰면 쉬는 상태 픽셀이 오늘과 동일**함을 픽셀 단면으로 확인했다.

**→ 반드시 «2층»으로 쓴다.** 그리고 **`background` 단축을 쓰지 마라** — 단축은 `background-image` 를 리셋한다.

### 1-4. 고칠 자리 — 파일:라인 (신규 파일 0 · 신규 오버레이 0 · 신규 색 0 · 신규 문자열 0)

#### (A) `src/components/strike/StrikeMap.tsx:290-296` — `pillHtml` 의 `box` 문자열

`background:${CASING};` **한 토막을 아래 세 줄로 교체**한다(순서 그대로).

```
background-color:var(--strike-hit-face,${CASING});
background-image:linear-gradient(var(--strike-hit-plate,#0000),var(--strike-hit-plate,#0000)),
                 linear-gradient(var(--strike-hit-face,${CASING}),var(--strike-hit-face,${CASING}));
background-clip:content-box,border-box;
```
그리고 같은 문자열의 `color:${color};` 를 `color:var(--strike-hit-ink,${color});` 로 바꾼다.

⚠ **`border:1px solid ${color}` · `padding:3px 8px` · `min-height:${HIT_MIN_PX}px` · `font-size:11px` ·
`font-weight:600` · `width:max-content` · `max-width` 는 한 글자도 건드리지 마라** → 상자 불변 → 2.5.8 불변.
⚠ **장식 pill 4개(무대)도 같은 `box` 를 쓴다.** 그쪽은 `[data-strike-hit]` 이 아니라 변수가 **영영 설정되지 않으므로**
폴백(`#0000` · `#ffffff` · tone)으로 **오늘과 픽셀 동일**이다. **문자열을 두 벌로 가르지 마라**(«두 벌이면 한쪽만 고쳐진다»).
⚠ 주석에 남길 것: *«`background` 단축을 쓰지 마라 — `background-image` 를 리셋한다. 그리고 층을 «둘»로 유지하라 —
1층이 되면 `background-clip` 둘째 값이 버려져 **흰 padding 면이 통째로 사라진다**(실측).»*

#### (D) `src/app/globals.css` — `:207`(`:focus-visible` 블록) **바로 뒤**에 추가

기존 두 규칙(`[data-strike-hit]` · `[data-strike-hit]:focus-visible`)은 **한 글자도 고치지 않는다.**

```css
/*
 * 9/4 지도 마커 히트의 **선택 표시**(사용자 지시 ① · 2026-09-01 · `MAP-EMPHASIS.md` §1).
 * ★★ «링»이 아니다 — 요소 «안»(content-box)에 불투명 판이 들어선다. 위 표의 포커스 3종과 **다른 방향**이다.
 * ⚠ `box-shadow` 를 쓰지 마라 — 위 두 규칙이 그 속성을 이미 전부 쓴다.
 * ⚠ `outline` 을 쓰지 마라 — 투명 `outline` 은 고대비 모드 보험으로 예약돼 있다(위 규칙).
 * ⚠ `transition` 을 붙이지 마라 — `prefers-reduced-motion` 전역 무효화로 그 사용자에게 뜻이 사라진다.
 * ★ 대비를 «타일에 안 묻는다»: 판의 이웃이 전부 우리 것이다 —
 *   판 `#1a1a1a` ↔ 흰 padding 링 / 흰 배지 바탕 `#ffffff` = **17.40 «고정»**.
 *   그리고 **타일과 맞닿는 픽셀(pill 의 tone 1px 테두리 · 배지의 흰 2px 링)은 한 개도 안 바뀐다**
 *   → **1.4.11 «노출»이 늘지 않는다.**
 * ⚠⚠ 판을 `background-color` 로 만들지 마라 · pill 테두리를 흰색으로 뒤집지 마라 —
 *   둘 다 «타일과 맞닿는 픽셀»을 바꾸고, 그 순간 어두운 타일에서 `#093389` ↔ `#1a1a1a` = **1.53** 이 된다
 *   (위 이중 링 문단이 기각한 바로 그 실패다).
 */
[data-strike-hit][aria-pressed="true"] {
  --strike-hit-plate: #1a1a1a;
  --strike-hit-ink: #ffffff;
}

/* 고대비(강제색) 모드 — 위 판은 `background-image`(그러데이션)라 그 모드에서 그려진다는 보장이 없고,
   `background-color`·`border-color`·`color` 는 시스템이 «강제 치환»한다. 그대로 두면 **그 모드에서 선택 전/후 차이가 0** 이다.
   ⚠ 여기서 `background-color` 를 «직접» 쓰지 마라 — 인라인이 이긴다. 반드시 «변수»로 내린다.
   ★ 시스템 색은 그 모드에서 «명시하면» 존중된다 — 보장된 유일한 수단이다.
   ⚠ 이 블록은 **미실측이다**(`MAP-EMPHASIS.md` §9-2). 게시 전에 반드시 재라 — 차이가 0 이면 게시 조건 미달이다. */
@media (forced-colors: active) {
  [data-strike-hit][aria-pressed="true"] {
    --strike-hit-plate: transparent;
    --strike-hit-face: Highlight;
    --strike-hit-ink: HighlightText;
  }
}
```

#### (E) `StrikeMap.tsx` — 동기화 effect 1개 (`Esc` effect `:1289-1304` **뒤**에 신설)

```ts
/* 선택 표시 동기화 — 열린 팝업의 «주인»을 지도 위에서 가리킨다(지시 ①).

     ③ 포커스 복원을 넣으면 `focusin` 이 다시 발화해 **선택할 때마다 지도가 움직인다**(`panTo`).
     여기서는 **속성 하나만** 바꾼다 — 노드가 유지된다.
   ★ 해제 4경로(같은 것 재클릭 :1004 · 지도 빈 곳 :1200 · bounds 밖 자동 :1281 · `Esc` :1291)와
     거리뷰 토글(:1040)·「거리뷰 보기」(:1076)가 **전부 `popup` 을 지난다** → 되돌림이 자동이다.
     **별도 정리 코드를 만들지 마라.** */
useEffect(() => {
  const node = mountRef.current;
  if (node === null || status !== "ready") return;
  const open = popup?.feature.id ?? null;
  for (const el of node.querySelectorAll<HTMLElement>("[data-strike-hit]")) {
    el.setAttribute("aria-pressed", el.dataset.strikeHit === open ? "true" : "false");
  }
}, [popup, status]);
```

| 쌍 | 왜 안 겹치나 |
|---|---|
| **선택 ↔ 포커스** | ① 속성이 다르다(`background-image`/`color` ↔ `box-shadow`/`outline`) ② **지면이 다르다** — 판은 요소 «안»(content-box), 링은 요소 «밖»(0~4 px). ③ 게다가 보통은 **동시에 안 뜬다**(팝업이 포커스를 가져간다) |
| **선택 ↔ 강조** | ① **층**이 다르다(마커 DOM ↔ 도형 오버레이 + 지도 밖 판) ② **색**이 다르다(선택 `#1a1a1a` = *«의미를 지지 않는 중립색»* `StrikeMap.tsx:95` ↔ 강조 `#093389` = 의미색) ③ **지속**이 다르다(누른 동안 한 개 ↔ 상시) ④ 대상 집합이 반대로 갈린다 — 선택 5개 중 **4개는 도형이 없고**, 강조 2개는 **둘 다 도형을 가진다** |
| **강조 ↔ 확신도** | 강조가 쓰는 것은 **형태·z·glyph·placement·지도 밖 판**이고, 확신도가 쓰는 것은 **선종·`stroke-dasharray`·`fillOpacity`·「±30 m」** 다. **출력 필드가 한 개도 안 겹친다.** ★ 이것이 M-70 «두 축이 다르다»를 이 안이 지키는 형태다 |

그래서 다른 지물의 `tone` 을 강조 목적으로 바꾸는 것은 ⛔ 다(§7-6).

| ②-1 판 테두리 | `#093389` ↔ 페이지 흰 | **11.37** | 결정적(페이지 배경) |
| ②-1 판 본문 | `#1a1a1a` ↔ `#eff6ff` | **16.00** | AAA |

★★ **«노출»이 늘지 않는다:** 이 안이 새로 만드는 «우리 색 ↔ 타일» 경계는 **0개**다.
타일과 맞닿는 픽셀은 오늘과 **한 개도 다르지 않다**(pill = tone 1 px 테두리 · 배지 = 흰 2 px 링 · 도형 = 흰 casing).
→ **타일 표본이 «필요 없다».**
⚠ 단 **위 값은 계산이고 렌더 실측이 아니다.** §9-1·§9-9 가 실측 항목이다.

### 4-2. WCAG 2.5.8 터치 대상 24 px — **구조로 불변**

이 안이 바꾸는 값 중 **`getBoundingClientRect` 를 만드는 것이 하나도 없다:**
`background-color`/`background-image`/`background-clip`/`color`/커스텀 속성/`aria-pressed` — 전부 페인트 값이다.
`border-width`·`padding`·`min-height`·`width`·`font`·`transform` 은 **한 글자도 안 고친다.**
② 는 도형을 **아예 안 고친다**(그리고 도형은 `clickable:false` 라 마커가 아니다).
가상 요소·`box-shadow`·`outline` 도 안 쓴다 → 시각 사각형조차 요소 밖으로 안 나간다.

`360×640 · 스크롤바 0 · dpr 1 · 루트 12px · 상자 336×420 · z16`):

|---|---|

반증 라운드의 **67.98 px(360 단독 재측정)** 은 **측정 집합이 다른 세 값**이다.
**회귀 기준은 «같은 환경표에서 변경 전/후 delta 0»** 이지 어느 절대값 인용이 아니다(§9-3).

### 4-3. 텍스트 확대 200%

- **①: 영향 0.** pill·배지는 **화면 고정 px** 이다(`font-size:11px` · `min-height:24px` — `pillHtml` 주석이
  *«폰트를 `rem` 으로 바꾸지 마라»* 로 못박았다). 루트 폰트가 24 px 이 돼도 마커 기하가 안 변한다.
- **②-1: 세로 예산이 늘고, 가로는 미측정.** `p-3`(0.75rem) + `border-2` 2 px → 루트 12 px 에서 **+22 px**,
  루트 24 px 에서 **+40 px**. **가로 넘침은 재지 않았다 — §9-7 이 필수 항목이다.**
- ⚠ **범례 조판은 안 건드린다**(§6-7) → «최장 어절 9자» 판정선이 안 움직인다.

**⚠ 못 쟀다:** 4-1 의 대비값은 전부 **계산**이다. 4-3 의 ②-1 가로 넘침은 **안 쟀다**.
4-2 는 «구조로 불변»이지 «재서 통과»가 아니다. **셋 다 §9 로 넘긴다.**

## 7. 하지 마라 목록 (되돌림 방지)

1. ⛔ **`background` 단축을 쓰지 마라** — `background-image` 를 리셋해 판이 통째로 사라진다. `background-color:` 로 써라.
2. ⛔ **배경 이미지 층을 «하나»로 줄이지 마라**(«둘째 gradient 가 중복 같다»로 지우지 마라) — 그 순간
   `background-clip` 둘째 값이 버려져 **흰 padding 면·배지 점선 틈이 통째로 타일이 된다.** 실측 확인된 결함이다.
3. ⛔ **선택 표시를 인라인 `box-shadow` 로 굽지 마라**(8/28 `RallyMap.tsx:431·450·462` 형태) — `StrikeMap.tsx:205` 가
   명시한 «링이 안 나온다»가 그대로 난다.
4. ⛔ **선택 표시를 `outline` 으로 만들지 마라** — `globals.css:206` 의 고대비 보험을 죽인다.
5. ⛔ **선택 표시를 «링»으로 만들지 마라** — `globals.css:181` 포커스 3종 계약. 넷째 링은 셋째의 변형이 된다.
6. ⛔ **`tone` 을 강조 목적으로 바꾸지 마라**(무대 2 를 `go` 로 올리는 것 포함) — 색은 «성격 축»이고,
   올리면 «갈 곳»이 **구역과 무대 둘로 갈라진다.** 그리고 1.32 m 떨어진 파란 원 + 파란 사각형이 z16 에서 한 덩어리로 뭉친다.
7. ⛔ **`strokeWeight`·`casingWeight`·`fillOpacity`·`strokeStyle` 을 강조·선택으로 흔들지 마라** — 전부 확신도/1.4.11 임자.

8. ⛔ **`setIcon` 재렌더 경로를 만들지 마라.** 선택은 **속성 하나만** 바꾼다.
9. ⛔ **pill 상자·padding·`min-height`·`border-width`·폰트를 만지지 마라** — 2.5.8 재측정이 딸려 오고

10. ⛔ **범례 9행의 개수·순서·문면·glyph·조판을 건드리지 마라.** 강조를 범례로 «흘리지» 마라(§6-8).
11. ⛔ **마커 `zIndex`(pill 1000+i · 배지 100+i)를 만지지 마라** — 범례 행 순서와 한 쌍이다.
12. ⛔ **②-1 판의 테두리를 빼지 마라**(틴트 단독 1.09) · **링크·셰브런·hover 를 붙이지 마라**(카드 = 외부 이동).

14. ⛔ **`transition` 을 붙이지 마라**(모션 축소 사용자에게 뜻이 사라진다 · 측정 시 전이 중간값 함정도 함께 온다).
15. ⛔ **`67.54` / `68.0` / `67.98` 을 섞어 인용하지 마라** — 측정 집합이 다른 세 값이다. 회귀는 **전후 delta** 로 판정한다.
16. ⛔ **«원본 사진이 무대 2 를 강조했다»로 적지 마라** — **안 했다**(무대 1·2·3 금색 화소 1256 동일).

18. ⛔ **`aria-pressed` 를 장식 pill·장식 배지에 넣지 마라**(`aria-hidden` 뒤다).

### 8-1. **②의 «강조»는 지도 «안»에서 새로 생기지 않는다. 이 결과를 받으실 것인가?**

- **지금 서는 것**: 코스콤지부 구역은 캔버스에서 **이미 5중 유일**(파랑 도형·사각형·최상위 z·`▨`·유일한 오른쪽 pill)이고,

  **조합원이 «강조된 것 = 더 확실한 것»으로 읽는다.** 그리고 코스콤 구역의 잉크를 키우면
  **1.3 m 떨어진 무대 2 를 더 가린다** — 강조하라고 하신 바로 그 무대다.
- **교환 조건**: 캔버스 강조를 반드시 원하시면 «점선 = 근사» 또는 «옅은 면 = 범위 근사» **둘 중 하나를 버려야** 한다.
  → **버리시겠는가? 버린다면 어느 쪽인가?**
