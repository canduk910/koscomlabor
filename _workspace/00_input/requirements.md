# 요구사항: 메인페이지 (탭 게시판)

작성일: 2026-08-16 | 요청자: 사용자 | 유형: 신규 기능 (콘텐츠 검증 게이트 불필요 — 게시 콘텐츠 없음)

## 기능 요구사항

1. **메인페이지에 탭으로 이동할 수 있는 게시판**을 띄운다
2. 탭 구성 (3개):
   - **공지사항** — `content/notices/` 기반 목록
   - **금융노조 소식** — `content/news/` 기반 목록
   - **방명록** — 조합원이 글을 남기는 게시판 (백엔드 필요)
3. **백엔드 서버는 NCP(Naver Cloud Platform)를 사용할 예정** — 아직 미구축.
   방명록은 API 추상화 계층을 두고, 백엔드 미연결 상태에서는 정직하게 "준비 중" 상태를 표시한다 (가짜 동작 금지)

## 제약사항

- 공지/소식 목록은 verified 콘텐츠 필터를 통과한 것만 표시 (union-webapp-dev 규약)
- 현재 content/가 비어 있으므로 **빈 상태(empty state) 설계 필수**
- 실제 노조 공지·소식처럼 보이는 가짜 콘텐츠를 만들지 않는다 (정밀검증 원칙). 플레이스홀더는 명백한 플레이스홀더여야 한다
- 디자인은 union-design-system 기준 (본문 18px, 대비 AAA 목표, 모바일 우선)
- 탭은 키보드 접근 가능해야 한다 (ARIA tabs 패턴)
