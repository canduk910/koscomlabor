# 리더 확정 — 노동교육 게시 데이터 (2026-08-17)

fact-verifier 1차 게이트(`_workspace/01_verifier_factcheck.md`) 결과에 대한 리더·사용자 판정.

## 판정: 5건 전부 게시 (사용자 확인 완료)

검증자 권고는 "금융노조 공식 3건만"이었으나, **사용자가 5건 전부 게시를 선택**했다.
조건부 승인 2건의 **완화 조치는 전부 적용한다** (§8 수정 요구 사항 이행).

`posts` 테이블에 `category = "education"`, `type = "link"` 로 등록한다.

### 제목 — 검증자 §7 문안 채택 (사용자 원본 라벨 미사용)

사용자가 준 라벨(`오바마`, `진중권`)은 **인물명뿐이라 클릭 전 내용을 알 수 없고,
노조가 그 인물을 지지·홍보한다는 인상**을 준다. 검증자 §8 요구대로 교체했다.
`산별중앙교섭` 라벨은 실제 제목의 **"및 노동쟁의절차"** 가 누락돼 있었다 —
조합원 권리 행사와 직결되는 정보라 제목에 살렸다.

### source — 화자·채널 구분 표기 (검증자 §8 필수 요구)

`source` 필드에 채널명을 넣어 **금융노조 공식 제작물과 외부 채널을 카드 표면에서 구분**한다.
`오바마`(개인 채널 재업로드)·`진중권`(민간 강연기업)이 노조 제작물로 오인되면 안 된다.
→ **`PostList` 가 링크형 카드에서 `source` 를 실제로 렌더하는지 반드시 확인할 것.**
렌더하지 않는다면 이 완화 조치가 무력화되므로 렌더하도록 고쳐야 한다 (개발자 필수 확인 항목).

### 금지 사항 (검증자 §5 근거)

- **`진중권` 건에 "교수" 직함 표기 금지** — 현재 직함 미확인
- **`진중권` 건에 강연 연도 표기 금지** — 업로드 2016-01-07 vs 설명문 2019년 행사로 시점 확정 불가
- **`오바마` 건에 "발언" 이상으로 내용 단정 금지** — 미시청
- 5건 모두 **영상 미시청 상태의 메타데이터 검증**이다. 설명을 창작하지 마라

### URL 정규형 — `www.youtube.com/watch?v=` 채택

디자이너 권고(§15.6.5)를 채택한다. `youtu.be` 는 단축 도메인이라 카드 메타의 도메인 표기가
넓은 연령대에서 "유튜브"로 연결되지 않는다. `?si=` 트래킹 파라미터는 제거 완료
(검증자가 제거 후 정상 리다이렉트 확인).

## 표시 순서 문제 (개발·운영 주의)

의도한 표시 순서는 **학습 순서**다: 노동조합 개념 → 산별노조 → 중앙교섭·쟁의절차 →
외부 채널 2건.

그런데 목록 정렬은 `urgent DESC, published_at DESC` 이고 **`publishedAt` 은 서버가 자동
기록하며 입력·수정할 수 없다**(06 명세 §15-6 판정). 따라서 순서를 맞추려면
**표시순의 역순으로 등록**해야 한다 (5 → 4 → 3 → 2 → 1 순으로 INSERT).

- 이 방식은 **사용자가 나중에 admin 에서 글을 추가하면 맨 위로 올라간다.** 학습 순서가
  깨질 수 있음을 사용자에게 안내할 것
- 근본 해결(수동 정렬 필드)은 이번 범위 밖. **후속 과제로 기록한다**

## 후속 점검 항목 (QA 인계)

- **링크 정기 점검 대상 등록**: `오바마` 건은 개인 채널 재업로드로 예고 없이 삭제될 수 있다
  (검증자 §8-#3-3). 나머지 4건도 외부 링크이므로 점검 대상에 포함
- **자막 제공 여부 미확인** — 접근성 관점에서 QA 확인 권장 (검증자 §6)
- 게시 후 2차 검증(최종 게이트): 검증자 §10 기준값 표와 실제 렌더 결과를 대조
