## ★ 리더가 지목하는 검증 쟁점 (반드시 판정할 것)

1. **무대 번호 충돌 — 최우선.**
   지도(map.png)는 `무대2(LED)`·`무대3(LED)`로 쓰고,
   지부배치도(official.jpeg)는 `LED무대 (KBS삼거리)`·`LED무대 2 (산업은행 옆)`로 쓴다.
   **지부배치도의 `LED무대 2` = 지도의 `무대3(LED)`** 로 보이는데,
   두 이미지를 **같은 화면에 나란히 놓으면** 조합원이 `LED무대 2` 를 지도의 `무대2(LED)` 로
   읽고 **집회 2구역으로 갈 수 있다.** 이는 §5.4 계열의 실제 오도 경로다.
   (이 페이지는 이미 `여의도공원 쪽` 금지어를 *"조합원을 2구역으로 보낼 수 있다"* 는
    같은 이유로 유지하고 있다.)

2. **캡션 `주최측 배치도` 가 map.png 에도 유효한가.**
   `page.tsx` 블록 2 주석은 *"화살표·강조 테두리·크롭을 넣지 마라. 주최측 원본이라는 것이
   이 이미지의 존재 이유"* 로 명시한다. 신규 map.png 에는 **화살표와 코스콤 로고가 있다.**
   → 주최측이 배포한 것인지, 지부가 가공한 것인지 **출처 등급 판정 필요.**
   §2 는 2급 자료에 출처 명기를 게시 조건으로 건다. 캡션이 곧 이 블록의 **유일한 출처 표기**다.

3. **주황 사각형이 가리키는 지점 ↔ 현재 게시 문안의 정합.**
   현재 렌더 문장: `코스콤지부는 집회 3구역입니다.` /
   `국회의사당역 3번 출구에서 여의도공원 쪽으로 약 230 m — KDB산업은행 앞입니다` /
   `3구역은 나란한 두 구역 중 북동쪽 — KDB산업은행 쪽입니다.`
   그리고 지도 컴포넌트(`RallyMap`)의 3구역 폴리곤·범례.
   신규 이미지가 **3구역 안의 특정 지점**을 찍었다면, `약 230 m`·`3구역 앞뒤 어디` 같은
   **파생 수치가 흔들리는지** 확인하라(§5.5 파생값 전수 검색).

4. **사용자가 지정한 캡션 문면 `(금융노조지부배치도)`.**
   사용자 지정 문면은 원칙적으로 불변이다. 다만 **사실 주장 부분은 확인 대상**이다 —
   이 자료가 실제로 **전국금융산업노동조합(금융노조)** 이 만든 것인지,
   `지부배치도` 라는 이름이 내용과 맞는지. 표제 원문은 `총파업 총력투쟁 결의대회 지부별 배치도` 다.

5. **우측 `코스콤(1)` / `산업은행 인도` 상자의 의미.**
   이것이 **또 하나의 코스콤 위치**로 읽히면 본문(`3구역`)과 **두 자리를 말하는 셈**이 된다.
   괄호 숫자의 의미가 미확인인 채로 게시되는 것의 위험을 판정하라.

6. **모바일 판독성.**
   official.jpeg 는 1532px 폭 **문자 밀집 표**다. 360px 단말에서 지부명이 판독되지 않을 가능성이 크다.
   기존 배치도 이미지는 *"역할이 위치 안내가 아니라 출처 증거"* 라서 판독 불가가 치명적이지 않다는
   판정을 받았다(§36.9-1). **신규 표에도 같은 논리가 성립하는가**를 별도로 판정하라 —
   조합원이 이 표에서 `코스콤` 을 찾으려 할 것이기 때문이다.
