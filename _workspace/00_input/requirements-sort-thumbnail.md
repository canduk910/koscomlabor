# 요구사항 — 게시물 수동 정렬 + YouTube 썸네일 (2026-08-17)

## 사용자 요청 원문

> 노동교육 순서 고정되게 정렬기능도 추가하고 썸네일도 넣었으면 좋겠어.
> 혹시 유투브의 썸네일을 넣을 수는 없어?

## 발단

노동교육 5건을 게시할 때, 목록 정렬이 `urgent DESC, published_at DESC` 고정이고
`publishedAt` 은 서버 자동 기록이라 **수동 정렬 수단이 없었다.** 학습 순서
(노동조합 개념 → 산별노조 → 중앙교섭·쟁의절차)를 맞추려고 **역순 등록**이라는 우회를 썼고,
"사용자가 admin 에서 글을 추가하면 맨 위로 올라가 순서가 깨진다"는 한계를 그대로 안고 있었다
(디자이너 스펙 §15.6R-D3, 07 문서 §10.9). 이번 작업이 그 후속 과제다.

## 리더 확정 사항 (사용자 확인 완료)

### 1. 정렬: **전 분류 적용**

공지사항·금융노조 소식·노동교육 모두 수동 정렬 가능. 분류마다 정렬 사용법이 다를 이유가 없다.
지정하지 않은 글은 기존 규칙(긴급 우선 → 게시일 역순)을 따른다.

### 2. 썸네일: **서버 캐싱** (YouTube 직접 로드 아님)

우리 서버가 썸네일을 한 번 받아 저장하고 조합원에게 내려준다.

**채택 근거 (개인정보):** `i.ytimg.com` 에서 직접 로드하면 메인페이지를 여는 **모든 조합원의
IP·User-Agent·접속 시각·Referer 가 구글로 전송**된다. 이 프로젝트는 원문 IP 를 로그에 남기지
않고, 방명록 IP 도 HMAC 해시 + 90일 후 NULL 처리하는 기준을 세워 두었다(07 §2.5).
제3자에게 조합원 접속 정보를 흘리는 것은 그 기준과 어긋난다. 서버가 중계하면
**조합원 IP 는 구글에 닿지 않는다.**

**디자인 결정 번복 고지:** 디자이너는 §15.6R-F 에서 "영상이라는 이유로 iframe 임베드·썸네일
프리뷰를 도입하지 않는다"고 판정했다. 근거는 ① 외부 스크립트·쿠키 유입 ② 다수 임베드의
모바일 로딩·CLS 악화 ③ 카드 프레임 일관성 파괴 ④ 자동재생 위험이었다.
정적 이미지는 ①·④ 를 발생시키지 않고, ② 는 고정 종횡비 박스로 해소 가능하다.
**③(카드 프레임 일관성)만 실질 쟁점으로 남으므로 디자이너가 재판정한다.**

## 실측 확인 (리더, 2026-08-17) — 게시된 5건 전수

| videoId | maxresdefault | mqdefault |
|---------|---------------|-----------|
| `ATbGKR-Agmk` | 200 | 200 |
| `-WrzgLtvuPU` | 200 | 200 |
| `jeK7W_SADUs` | 200 | 200 |
| `Vj3lQ7Y71PU` (오바마) | **404** | 200 |
| `OFfbgB5dOIA` | 200 | 200 |

- **고해상도(`maxresdefault` 1280×720)는 항상 있는 것이 아니다** — 폴백 필수
- `mqdefault` (320×180, 16:9)는 5건 전부 존재. `hqdefault` 는 480×360 **4:3 레터박스**라
  16:9 카드에 넣으면 위아래 검은 띠가 생긴다 — **hqdefault 를 쓰지 마라**
- API 키·스크립트 불필요. 정적 URL + `<img>` 로 충분

## 비기능 요건

- 썸네일 취득 실패가 **게시를 막지 않아야 한다** (링크 프리뷰와 동일 원칙 — 06 §13.2)
- 썸네일 없는 게시물(작성형 공지 등)과 **같은 목록에 섞여도 레이아웃이 무너지지 않아야 한다**
- 정렬 변경은 **원자적**이어야 한다 (순서 번호 중복·누락 금지)
- 이미 게시된 5건에 썸네일을 **소급 적용**할 수단이 필요하다
- 06 명세·07 문서 갱신, 프로덕션 DB 마이그레이션 포함
