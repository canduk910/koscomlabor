# 입력 — 배너 설명에 «사내게시판·SMS 안내» 반영 (2026-08-26 · 라운드 3)

## 사용자 원 지시 (축자)

> 참석 예비조사 배너 설명에 "사내게시판과 SMS로 안내한 설문조사"라는 것을 반영해줘.

⚠ **«…라는 것을 반영해줘»** 다 — **축자 문면 지정인지 «이 사실을 전하라»인지 문면이 확정적이지 않다.**
다만 인용부호 안 문자열이 있으므로 **그것을 최대한 살리는 방향**이 사용자 의도에 가깝다고 본다.
**문면 확정은 검증자 소관.**

## D-1 · 현행 배너 (3줄) — 게시된 상태

```
[제목]   참석 예비조사 ↗                      text-body · font-bold · text-primary
[설명]   당일 QR 출석체크는 따로 해야 합니다.    text-body · text-ink        ← ★ 게시 조건. 빼면 게시 불가
[메타]   외부 링크(새 창) · docs.google.com     text-caption · ink-muted · break-all
```
카드 전체가 **단일 `<a>`** 이고 **내부 텍스트가 접근성 이름을 이룬다**(조건 10).
`aria-label`·`title` 금지 — 붙는 순간 설명 줄이 링크 낭독에서 사라진다.

## D-2 · ★★ 최대 제약 — **높이 예산이 33px 밖에 없다**

QA 실측(360×640 · `phase` 별 · `18:30` 하단 기준):

| phase | `18:30` 하단 | 360×640 여유 |
|-------|-------------|-------------|
| `upcoming` | 579.9 px | **60.1 px** |
| **`today`**(상태 배지가 추가된다) | **609.9 px** | ★ **33.1 px** |

**배너가 한 줄 늘면 그만큼 `18:30` 이 아래로 밀린다.**
리더 개산(루트 12px): `text-body` 한 줄 ≈ 23px + `mt-1` 3px ≈ **26px** / `text-caption` ≈ 17 + 3 ≈ **20px**.
→ **`today` 에서 `text-body` 로 한 줄 더하면 여유가 7px 로 줄어든다.** ⚠ **개산이다. 실측이 필요하다.**

★ 이 판정선(`360×640`)은 이번 라운드에 **프로젝트 QA 판정선으로 승격**된 값이다
(`union-qa-testing §5.7` · 종전에는 뷰포트 «폭»만 있었다).

## D-3 · 사실 확인

«사내게시판과 SMS로 안내한 설문조사» 는 **지부 자신의 배포 행위**에 대한 진술이라 **당사자 진술 = 1급**이다.
⚠ 다만 **«그 안내에 쓰인 설문이 우리가 링크하는 이 폼과 같은가»** 는 별개 사실이다 — 사용자가
«참석 예비조사 배너 설명에» 라고 지목했으므로 같은 것으로 읽히나, **검증자가 판정**하라.

★ **이 문장은 오히려 혼동을 줄일 가능성이 있다** — 이미 SMS 로 응답한 조합원이
«같은 것이구나» 로 알아보면 **중복 응답을 막는다.** 다만 **«이미 했으면 안 해도 된다»를 우리가
말하는 것은 아니다**(그건 지부 운영 판단이고 근거가 없다).

## D-4 · 지켜야 하는 것

1. **설명 줄 `당일 QR 출석체크는 따로 해야 합니다.` 는 게시 조건**이다. 새 문장이 **이것을 대체·축약·이동**시키면 안 된다.
2. **접근성 이름에 그 문장이 계속 포함**돼야 한다(AX 트리 계산된 이름으로 확인).
3. **`aria-label`·`title` 금지** 유지.
4. **금지어**: `참석 등록`·`참석 신청`·`사전 등록`(혼동을 반대로 민다) · `식대 및 교통비 5만원`.
5. 200% 확대 — 새 문장의 **공백 없는 최장 덩어리**를 `width:0` 의 `scrollWidth` 로 재라.
   `사내게시판과`(6자)·`설문조사입니다`(7자) 가 후보다. 배너 슬롯은 **215px**(실측).
