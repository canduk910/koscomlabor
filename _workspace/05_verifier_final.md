### U-1. 프리렌더 HTML 을 계속 쓸 것인가 — **쓴다. 단 3계층으로 쓴다**

리더 지적대로 `.next/server/app/*.html` 은 **서버 없이 동결 산출물을 직접 보는 가장 가까운 대조 대상**이고
`<!-- -->` 도 그대로 있다. **버린다면 그 이점을 잃는다.** 구멍은 계층을 더해 메운다.

| 계층 | 무엇을 보나 | 도구 |
|---|---|---|
| ① 프리렌더 본문 텍스트 | 서버가 확정한 문안 | `<!-- -->` 제거 후 태그 제거 |
| ② **속성 텍스트** | `aria-label`·`title`·`alt` — **스크린리더 사용자의 본문** | 속성 정규식 전수 |
| ③ **소스 문자열 집합 차분** | **클라이언트 전용까지 전부** | `git show <배포커밋>:<file>` vs 현재 |

> **계수는 `grep -o | wc -l` 로 한다. `grep -c` 를 쓰지 마라** — 이 HTML 은 한 줄이라 **모든 값이 1로 보인다.**

### U-2. ★ innerText 를 안 쓰는 이유 — **문자열 게이트에는 ③이 더 강하다**

`innerText` 는 **그 순간 실행된 분기만** 보여준다. 플래그·상태·뷰포트에 따라 안 그려진 문자열은 **없는 것과 구분되지 않는다.**
③ 집합 차분은 **저작된 문자열 전부**를 보므로 **실행 여부와 무관**하다 — 이번에 `지도 크게 보기` 가 신규 저작이 아님을
증명한 것이 정확히 ③이다.

**innerText 가 필요한 판정은 따로 있다** — **배치·가림·순서·실제 표시 여부**. 그것은 **QA 소관**이고 30-B 가 한다.
**두 게이트가 다른 것을 보는 것이 맞고, 겹치면 둘 다 약해진다.**

**대상**: 이 페이지의 외부 링크는 **1개뿐**이다(`https://prpage153.mycafe24.com/bank701/index.php`). QR 이미지 **0**.

|---|---|

| 표시 도메인 | ⭕ `prpage153.mycafe24.com` — `href` 와 일치 |

#### ★★★ 원본 HTML 을 읽어서 찾은 것 — **시각 판정창이 «8/28 값»이다**

⚠ §5.8 대로 **마크다운 변환이 아니라 원본 HTML** 을 봤다. 도착지는 `<script>` 로 시각을 판정한다:

```js
var startTime1 = "18:30:00";  var endTime1 = "19:20:00";
var startTime2 = "19:20:01";  var endTime2 = "22:00:00";
// 이 범위 안이면 notice.php 로 자동 이동
```

★ **`18:30`·`19:20` 은 8/28 결의대회(저녁 집회)의 1차·2차 출석 시각이다.** 9/4 총파업은 **11:00~15:15 낮 집회**다.
→ **지금 상태로 9/4 낮에 이 링크를 누르면 「지정된 시간에만 체크 가능합니다.」 화면에 머문다.**

##### 그래서 무엇이 참이고 무엇이 아닌가 — **갈라 적는다**

| | |
|---|---|
| ⭕ **우리 카드 두 문장은 이 상태에서도 «거짓이 아니다»** | 「당일 지정된 시각에만 체크됩니다.」 는 **정확히 이 거동을 설명한다.** §57-1 이 *「시각 미정의 위험은 작다 — 도착지가 스스로 막는다」* 로 판정한 **바로 그 구조**다 |
| ⭕ **본문 「인증 시각은 추후 안내합니다.」 도 확증됐다** | 도착지에 9/4 시각이 **반영돼 있지 않다** — 그 문장이 참임을 실측이 뒷받침한다. **빼지 마라** |
| ⚠ **그러나 «9/3~9/4 에 열려 있는가»는 여전히 확인 불가** | 주최측이 그 전에 갱신할지는 **미래 사실**이다 |
| ★ **§57-2 재확인 조건의 «근거»가 바뀌었다** | 종전: *「2급 출처라 다시 열어 본다」* → **지금: 「도착지가 8/28 시각창을 그대로 들고 있는 것을 실측했다」.** **훨씬 구체적이고 무겁다** |

##### ★ 게시 조건 **62**(§64-3 에 이어) — 재확인 항목을 **3개로 늘린다**

```
9/3~9/4 에 도착지를 다시 열고 «셋 다» 확인한다:
  ① HTTP 200
  ② <title> = 「금융노조 집회참석」
  ③ ★ 원본 HTML 의 startTime/endTime 이 «낮 시간대»로 바뀌었는가
     — 2026-09-01 현재 18:30:00~22:00:00 (8/28 값)
```
⚠ **①②만 보면 이 항목을 놓친다** — 시각창은 **본문에 안 보이고 `<script>` 안에 있다.**
⚠ **③이 8/28 값 그대로여도 «게시 철회»가 아니다** — 우리 문면은 그 상태에서도 참이고, 링크를 빼면 **§57-1 이 기각한 «8/28 조건이 통째로 딸려 오는» 경로로 되돌아간다.** ★ **관측해서 리더에게 알리는 것까지가 이 조건이다.**

### 72-2. ★★ V-a 판정 — **게시한다.** 다만 리더 전제 하나를 정정한다

#### ⚠ 먼저 정정 — **「한 번만」이 아니라 「같은 것」이 핵심이다**

### 74-1. ★★ (가) 세 장의 성격 — **판별기가 이미 있다. 셋 다 «출처 증거»다**

리더 질문(*「로드뷰는 «찾는 도구»에 가깝지 않나」*)에 **감각으로 답하지 않았다.** 8/28 이 그 판정의 **숨은 전제**를 명시로 적어 뒀다(`01_verifier_factcheck.md:7730`):

> *「«출처 증거»가 성립했던 **숨은 전제**는 **«같은 정보를 지는 다른 도구가 페이지에 있다»**(지도 + 본문 3줄)였다」*

★ **그 전제를 세 장에 각각 재면 답이 나온다:**

| 사진 | 그 사진이 지는 정보 | **같은 정보를 지는 «다른 도구»** | 판정 |
|---|---|---|---|
| **배치도** | 코스콤 = 무대 2 구역 | ⭕ `KOSCOM_LOCATION_NOTE` + 범례 2·3행 | **출처 증거** |
| **지도** | 무대 4 · 임시화장실 2 · 코스콤 사각형 | ⭕ **네이버 지도 + 범례 9행** | **출처 증거** |
| **로드뷰** | 코스콤 구역의 실제 모습 | ⭕ **거리뷰 기능**(`roadview` 에 `koscom-area` 포함) + 범례 3행 「코리아나호텔(폴바셋) 앞」 | **출처 증거** |

→ ⭕ **세 장 다 전제가 선다. 성격이 갈리지 않는다. 묶음 유지.**

#### ⚠ 그러나 로드뷰만 «조건»이 하나 붙는다 — 명시로 남긴다

**거리뷰 기능은 `NAVER_MAP_CLIENT_ID` 조건부다.** 키가 없으면 지도 섹션이 통째로 사라지고 **그 기능도 사라진다.** 그때 로드뷰 사진은 **코스콤 구역의 «유일한» 시각 경로**가 된다 — 즉 **8/28 이 말한 숨은 전제가 그 조건에서 깨진다.**
→ ⚠ **그래도 자리를 가르지 않는다**: 키가 없어도 **사진은 남고 스크롤로 도달한다.** «출처 증거 → 찾는 도구»로 격이 올라도 **그것이 «위로 올려라»를 뜻하지 않는다**(§0.4 는 «숨김»을 막지 «아래»를 막지 않는다).
→ ★ **두 문장을 한 벌로 적어라** — 안 적으면 다음 사람이 «401 이면 유일 경로인데?»로 자리를 되돌린다.

### 74-3. (다) 순서 — **`지도 → QR 한 줄 → 총파업 일정 → 원본 자료 → 돌아가기` 확정**

⚠ **리더 우려의 «방향»을 정정한다.**
리더: *「QR 한 줄 자리 근거(C-10)가 «표 뒤에 두면 안 읽힌다» 인데, **그 표가 더 길어졌다**」* → 걱정의 뉘앙스로 적혀 있다.
★ **표가 길어지면 그 근거는 «강해진다».** 「표 뒤에 두면 안 읽힌다」의 강도는 **표 길이에 비례**한다. **우려가 아니라 보강 사유다.**

#### 개선폭 — 숫자로 적는다

```
현행:  총파업 일정 시작 3,498px  →  390×844 기준 «4.1 화면»
개정:  원본 자료 1,636px 이 뒤로 빠진다  →  3,498 − 1,636 = 1,862px  →  «2.2 화면»
★ 조합원이 행동 정보에 닿기까지 «1.9 화면» 당겨진다
```
⚠ **첫 화면 판정선(`360×640`)에는 영향 0** — 판정선은 **블록 1(`10시 30분`) 하단**이다.

#### ★ 죽여야 할 «암묵 근거» 하나 — 안 죽이면 되돌아온다

리더는 *「«바로 뒤»에 근거가 «없었다»」* 고 했지만, 다음 사람이 **암묵 근거를 스스로 만들 수 있다**: *「지도와 사진이 같은 대상을 말하니 «붙어 있어야 대조»가 된다」*.
→ ⛔ **그 근거를 미리 죽여라**: **대조는 «붙어 있어야» 성립하지 않는다.** 조합원이 지도를 보고 사진으로 내려가 대조하는 행동은 **가정된 것이지 관측된 것이 아니고**, 설령 한다 해도 **그 대조가 행동을 가르지 않는다**(§5.3). 반면 **«일정을 못 읽는 것»은 행동을 가른다.**

### 74-4. (라) 「원본 자료」 헤딩 — **랜드마크 통과 · 문면 통과**

#### 랜드마크(§8) — **`aria-labelledby`**

이 페이지 실측: **`gather-heading`·`overview-heading`·`map-heading`·`program-heading` — 4개 전부 `aria-labelledby`.**
§8 규칙(*「화면에 헤딩이 있으면 `aria-labelledby`, 없으면 `aria-label`」*) 그대로다.
→ ⭕ **`<h2 id="source-heading">원본 자료</h2>` + `<section aria-labelledby="source-heading">`.**
⛔ **`aria-label` 을 쓰지 마라** — 화면에 헤딩이 있는데 `aria-label` 을 붙이면 **둘이 갈리고**, 이 페이지 5개 섹션 중 하나만 규칙이 달라진다.

#### 문면 — **「원본 자료」 통과**

⚠ **§5.3 «우리 작업 사정을 쓰지 않는다»에 걸리는지 재봤다** → ❌ **안 걸린다.**
«우리 작업 사정»은 *「검증 중」·「반영 예정」* 류다. **「원본 자료」는 «자료의 성격»**이고, 이 섹션 세 장의 **공통 성질(«우리가 만들지 않은 것»)을 정확히 말한다.**
⚠ **8/28 캡션 「주최측 배치도」를 그대로 옮기지 마라** — 이번 3장 중 **로드뷰는 지부가 네이버 캡처에 그린 것**이라 **«주최측»으로 묶으면 거짓**이다.
★ 부수 효과: 「원본 자료」는 **«우리 페이지 내용이 이것의 요약»**임을 함의하는데 **그것이 참이다**(지도·일정·코스콤 위치가 전부 이 3장에서 나왔다).
