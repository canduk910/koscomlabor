## 판정: **통과** — 승인 원문과 실제 렌더가 전건 일치

1차 게이트(`01_verifier_factcheck.md`)에서 승인·조건부 승인된 5건이, 사용자 판정("5건 전부 게시")과
검증자가 요구한 완화 조치를 **모두 반영한 상태로** 프로덕션에 게시되었음을 확인했다.

## 1. 순서·제목·출처·URL 대조 (공개 API 실측)

`GET https://union-api.koscomlabor.cloud/posts?category=education` 응답 순서 그대로:

| 표시순 | title | source | url | 판정 |
|--------|-------|--------|-----|------|
| 1 | 노동조합이란 | 금융노조 교육문화본부 | `…watch?v=ATbGKR-Agmk` | ✓ |
| 2 | 산별노동조합이란 | 금융노조 교육문화본부 | `…watch?v=-WrzgLtvuPU` | ✓ |
| 3 | 산별중앙교섭과 쟁의절차 | 금융노조 | `…watch?v=jeK7W_SADUs` | ✓ |
| 4 | 오바마 대통령이 말하는 노조 | 하종강의 노동과 꿈 | `…watch?v=Vj3lQ7Y71PU` | ✓ |
| 5 | 노조가 필요한 이유 | 마이크임팩트 | `…watch?v=OFfbgB5dOIA` | ✓ |

**순서·제목·출처·URL 전건 일치.** 의도한 학습 순서(개념 → 산별노조 → 중앙교섭·쟁의절차 →
외부 채널 2건)대로 렌더된다. 역순 등록(⑤→①)으로 `published_at DESC` 정렬을 맞췄고,
게시일 충돌을 막기 위해 건당 1.1초 간격을 두었다.

## 2. 금지 사항 검사 (전건 통과)

| 항목 | 근거 | 결과 |
|------|------|------|
| "교수" 직함 표기 | §5-d 현재 직함 미확인 | 없음 ✓ |
| 강연 연도 표기 | §5-c 업로드 2016 vs 설명문 2019 로 시점 확정 불가 | 없음 ✓ |
| `?si=` 추적 파라미터 | 리더 메모 | 없음 ✓ |
| `youtu.be` 단축 URL 잔존 | §15.6R-D 판정 1 (정규형 통일) | 없음 ✓ |
| **"금속노조" 오기** | §2 경고 — WebFetch 가 실제로 이 오류를 냈다 | 없음 ✓ |
| 사용자 축약 라벨 잔존 (`오바마`·`진중권` 등) | §8 제목 교체 요구 | 없음 ✓ |
| 창작된 설명 문구 (`body`) | 5건 모두 영상 미시청 메타데이터 검증 | 전건 `null` ✓ |

`body` 가 전건 `null` 이고 카드에 설명 줄이 없으므로(§15.6R-C), **문안을 창작할 표면이
구조적으로 0** 이다 — 검증 범위를 넘는 서술이 화면에 들어갈 경로가 없다.

## 3. 완화 조치 이행 확인 — 채널명 구분 표기

검증자가 조건부 승인 2건에 건 **필수 조건**: "카드에 채널명을 노출해 금융노조 제작물이
아님을 구분할 것." 프로덕션 렌더 마크업 실측:

```
오바마 대통령이 말하는 노조 ↗
  2026.08.17 · 하종강의 노동과 꿈
  외부 링크(새 창) · www.youtube.com

노조가 필요한 이유 ↗
  2026.08.17 · 마이크임팩트
  외부 링크(새 창) · www.youtube.com
```

금융노조 공식 3건은 `금융노조 교육문화본부`/`금융노조` 로 찍혀 **외부 채널 2건과 즉시 구별**된다.
이 표시가 곧 게이트 조건의 이행이다.

**이 조건은 구현 단계에서 한 번 무력화될 뻔했다** — `PostList.tsx:98` 이 `source` 를
`!isExternal` 일 때만 렌더하고 있었고, 노동교육 5건은 전부 링크형이라 채널명이 어디에도
표시되지 않는 상태였다. 리더 실측으로 발견 → §15.6R-D 로 2행 메타 재설계 → 반영.
**검증 게이트를 통과한 조건이 구현 단계에서 조용히 사라질 수 있다**는 사례로 기록한다.

## 6. 미검증 / 한계 (게시 후에도 유효)

- **영상 5건을 시청하지 않았다.** 이번 게시는 메타데이터 검증에 근거한다.
  #3·#4·#5 는 설명문에 내용 서술이 없어 제목 외 근거가 없다
- **#4(진중권) 의 정파성·상업성 리스크는 해소된 것이 아니라 사용자가 감수를 선택한 것**이다.
  업로더가 직접 단 태그가 정치 논객 콘텐츠로 포지셔닝돼 있고 설명문이 유료 강연 티켓 판매
  퍼널이다. 조합원 반응에 따라 재검토가 필요할 수 있다
- **#3(오바마) 은 원출처 미표기 재업로드**로 예고 없이 삭제될 수 있다 → 링크 정기 점검 대상
- 5건의 **자막(캡션) 제공 여부 미확인** (접근성)
- **표시 순서는 취약하다**: 사용자가 admin 에서 글을 추가하면 맨 위로 올라가 학습 순서가
  깨진다. 정렬 수단(`sort_order`)은 후속 과제 (§15.6R-D3)
